# Development Journey

This is a starting narrative compiled from project notes and source inventory. Add dates, commits and evidence where available.

## Product evolution
CampusVoice began as a campus issue/feedback concept and expanded toward a broader institutional community and workflow platform. The documented product areas include issues, polls, discussions, announcements, structured feedback, role-specific workspaces and workflow operations.

## Engineering areas explored
- React-based desktop and mobile interfaces.
- Flask API routes and service-layer modules.
- MongoDB collection organization.
- Authentication and role-based experiences.
- Workflow, task, audit, SLA, escalation and notification concepts.
- Responsive Create flows and role-specific UI behaviour.
